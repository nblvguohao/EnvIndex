# 距离分层 LOEO 规模化结果（400-500 环境）

- **日期**：2026-08-05
- **执行**：服务器 `100.112.165.109`（2× A100），nohup 后台，~13 小时
- **配置**：小麦 ESWYT 800→分层 396 环境 + 玉米 G2F 200 环境；120 epochs，d_embed=32，rank=4，**batch 1024 + 折级并行（2 GPU）**
- **日志**：`/data/lgh/envindex/repo/data/scaled_train.log`

## 1. 结果

### 小麦 ESWYT（396 留出环境，距离分层抽样）

| 模型 | PCC (mean ± std) |
|------|------------------|
| G∘z（学习嵌入） | +0.108 ± 0.215 |
| G+E 加性 | +0.148 ± 0.195 |
| geno-mean GBLUP-lite | +0.148 ± 0.195 |
| random-z 对照 | +0.010 ± 0.147 |
| **Δ(e)** | **-0.040** ± 0.238 |

### 玉米 G2F（200 留出环境，距离分层抽样）

| 模型 | PCC (mean ± std) |
|------|------------------|
| **G∘z（学习嵌入）** | **+0.307** ± 0.190 |
| G+E 加性 | +0.293 ± 0.181 |
| geno-mean GBLUP-lite | +0.293 ± 0.181 |
| random-z 对照 | +0.003 ± 0.060 |
| **Δ(e)** | **+0.014** ± 0.085 |

## 2. 解读

1. **阴性对照验证通过**：random-z ≈ 0（小麦 0.010 / 玉米 0.003）——学习嵌入提供真实信号，非噪声。
2. **真实信号随规模增强**：玉米 G∘z 从 pilot 0.135（60 环境）→ 0.307（200 环境）。
3. **Δ 分作物方向不同**：玉米 +0.014（G∘z 略优），小麦 -0.040（G+E 优）。
   - 这是 H2"可预测性边界"的初步信号：显式 G×E 建模的收益因作物/环境类型而异。
   - 玉米为短期营养生长期作物（高遗传力、环境×基因型交互结构强）；小麦 ESWYT 国际试验跨大尺度环境，可能需更强模型或距离分层下高距离端弱化交互增益。
4. **G+E ≈ geno-mean GBLUP-lite**：pilot 构造上两者等价（环境均值+基因型偏差 vs 基因型均值）。

## 3. 局限

- EnvIndex 仍为 v0：<2M 参数、120 epochs、无标记基因型（学习 embedding 而非 GBLUP 内核）。
- 小麦特征用 IWIN 自带阶段均值（3A 路径），玉米用 GDD 阶段边界（改进1）。
- 距离分层抽样覆盖了距离梯度，但 Δ-dist 剂量反应曲线本身未在本轮计算（需 dist(e) 与 Δ(e) 的逐环境配对，下一步）。

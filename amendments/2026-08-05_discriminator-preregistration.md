## 2. 预注册阈值（冻结后不可后验调整）

### 2.1 MDE（Δ 检测功效）

| 阈值 | 玉米 | 小麦 |
|------|------|------|
| MDE 平均 Δ（名义 N） | 0.017 | 0.034 |
| **MDE 平均 Δ（N_eff 校正后）** | **0.026** | **0.048** |
| MDE 分箱对比（高/低 dist 半区） | 0.024 | 0.047 |

**决策规则**：
- Δ=0.03 仅在玉米（N_eff 校正后 MDE 0.026）可靠
- **小麦臂需 N_eff ≥ 300 或接受 MDE ≥ 0.05**——协议 §6 的"Δ=0.03"**修订**为分作物 MDE 值
- 功效 < 80% 时扩环境的判定以 **N_eff** 为准（非名义 N）

### 2.2 判别器指标与功效（结构性修订）

**关键发现**：斜率差判别器在当前 dist 分布下 **MDE=1.78–3.10，无功效**——dist SD 太小（0.007–0.027），斜率无法区分 z_e vs PCA。

**修订**：
1. **主判别器从"斜率差"改为"分箱均值对比"**：Δ(高 dist 分位) − Δ(低 dist 分位)，MDE 0.024–0.047（可行）
2. **判别器通过条件**：分箱均值差为负且 bootstrap 双侧 p < 0.05，且效应量 ≥ MDE 分箱对比值
3. **结构性前提**：H2 判别器需要 **dist 范围足够宽**——CIMMYT 远距环境（相对 T3 近距）必须纳入以拉开 dist 分布（验证 loe_scaling spec）。若最终 dist SD < 0.05（两作物），判别器判定为"无法区分"，H2 按证伪处理
4. 证伪触发（已有 §1 增强）：PCA 在 ≥2 作物同形递减 → H2 结构性证伪

### 2.3 d_crit 可接受宽度

- 预注册：d_crit CI 半宽 ≤ `0.2 × dist IQR`（玉米 0.0005 / 小麦 0.0004）
- **可行性警示**：当前 dist IQR ~0.002 下，d_crit 半宽阈值近乎不可达 → 同样指向需拓宽 dist 范围
- 若 CI 覆盖超出观测 dist 范围 → 报告"数据范围内无可辨识边界"（降级为 Relationship）

### 2.5 N_eff 聚类稳健推断

- ICC = 0.346（G2F 实测）→ **N_eff = N / (1 + (m−1)×0.346)**
- 玉米 N_eff = 83.9 / 小麦 194.3（名义 200/396）
- 所有功效分析、bootstrap CI、判别器检验**基于 N_eff**；敏感性分析报告名义 N 与 N_eff 两套结论

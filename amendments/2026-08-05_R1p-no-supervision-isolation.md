## 1. 问题定义

R1' 臂（无监督 R1 编码对照）的目的是**分离"编码器架构容量"与"产量监督学习信号"**：

> R1' 若隐式接触 plot 级产量监督 → R2 vs R1' 对比被混淆，对照失效。

具体混淆路径：
1. **主任务产量监督**（ŷ = G∘z 预测）若流入 R1' → R1' 不再是"无产量监督"
2. **aux A（环境均值）** 本身含环境级产量信息——这是**有意保留**的（§4.2 定义），但必须明确它不是 plot 级监督
3. 共享编码器权重/初始化 → 不构成泄漏

## 2. R1' 训练信号定义（严格）

**R1' 允许**：
- 辅助任务 A：环境均值读出（`EnvMeanHead`，训练集内估计）
- 辅助任务 B：InfoNCE 对比（env_label = year / mega-environment，协变量定义）

**R1' 禁止**：
- 主任务 G∘z 产量预测 head 的训练
- 任何 plot 级产量残差作为目标
- 从测试/留出环境的产量估计任何统计量

## 3. 代码级隔离（非文档约定）

1. **独立损失函数**：R1' 的 loss = `λ_A·L_auxA + λ_B·L_auxB`，**主任务系数恒为 0**
2. **参数冻结**：R1' 训练时 `InteractionHead` 不更新（或不存在）；只有 `MLPMixerEncoder` + `EnvMeanHead` 更新
3. **断言**：训练循环内断言 `main_loss_weight == 0`，若违反则抛异常中止
4. **manifest 可追溯**：每个 R1' 结果记录 `{"arm": "R1'", "supervision": ["auxA", "auxB"], "main_task_weight": 0.0}`；审计脚本校验该字段

## 4. 残留泄漏点与声明

| 信号 | 是否泄漏 | 说明 |
|------|----------|------|
| aux A（环境均值） | 非 plot 级泄漏 | 环境级信息，R2 也有 → 不构成 R1' vs R2 差异混淆 |
| InfoNCE（year） | 否 | 标签仅为 year/ME 协变量 |
| 主任务 | 禁止 | 代码级强制 |
| 环境均值在折内 | 安全 | 仅训练环境估计（§6 已有） |

**声明措辞**：R1' 是"**无 plot 级产量监督**的编码对照"，不是严格无监督（它有意用环境均值 aux A）。论文中如实表述，避免"无监督"过度声称。

## 5. 判定标准

- 若 R2 显著超越 R1'（Δ > MDE，§6 分作物值）→ 增量来自主任务产量监督 → 学习索引有监督价值
- 若 R2 ≈ R1' → 增益主要来自架构容量 + 辅助任务 → **如实报告为发现**（学习信号无增量）
- 此判定写入 G2 门评审，不做后验调整

## 1. 问题的数学本质

留出环境 e 内，任何加性模型的预测为

```
ŷ(g, e) = a_g + c_e        （c_e 在环境 e 内为常数）
```

因此**任何只依赖环境内基因型相对顺序的指标，都对 c_e 不变**——G+E 的环境项无论编码得多好，都不改变环境内排序。

### 1.1 数值验证（真实大麦数据，WRSBN_2016_Aberdeen，n=31）

| 指标 | G+E 基线 | geno-mean 基线 | 是否恒等 |
|------|----------|----------------|----------|
| PCC | 0.52400 | 0.52400 | **是** |
| Spearman | 0.45372 | 0.45372 | **是** |
| **NDCG@10%** | 0.93596 | 0.93596 | **是** |
| **SelectionGain@10%** | 747.30947 | 747.30947 | **是** |
| RMSE | 1856.69170 | 1804.06035 | 否 |

### 1.2 关键结论：原设想的候选方案无效

`2026-08-06_methodological-correction-delta-dist.md` §7 曾列"改用协议 §6 已有的 SelectionGain@10% / NDCG@10%"作为候选。**该方案在逐环境计算时不成立**——上表证明这两个指标与 PCC 一样退化。

指标的真正分类不是"PCC vs NDCG vs SelectionGain"，而是：

| 类别 | 指标 | 对 G+E 环境项敏感 | 可给出逐环境 Δ(e) |
|------|------|-------------------|-------------------|
| A 环境内**排序类** | PCC、Spearman、NDCG@k、SelectionGain@k | **否**（退化） | 是 |
| B 环境内**水平类** | RMSE、MAE、R²(未中心化) | 是 | 是 |
| C **跨环境池化类** | 池化 SelectionGain@10%、池化 NDCG | 是 | **否**（每模型仅一个数） |

H2 主图（Fig. 5 Δ–dist 曲线）**要求逐环境 Δ(e)**，故 C 类不能作为主指标——这排除了协议 §6 中 SelectionGain@10% 的池化定义。

## 2. 四个候选方案

### 方案 1：保留环境内排序指标，重写协议 §4.3 的基线论述

**做法**：承认 A 类指标下 G+E ≡ 基因型主效应，将基线正名为"**无 G×E 零模型**（固定基因型排序）"。

- **Δ(e) 含义**：环境特异的重排序，相对固定基因型排序的收益 = 环境条件化的**总价值**（编码 + 交互合并）
- **重跑成本**：**零**。现有四作物全部结果直接可用
- **协议改动**：§4.3 删除"共享 z_e 以消除编码质量混淆"的表述（该目标在 A 类指标下不可达）；§5 基线墙中 GBLUP-G+E 与 GBLUP-G 的环境内对比须标注为等价
- **代价**：无法分离"更好的环境编码"与"显式交互建模"两个成分——这是协议 §4.3 的核心设计意图，等于放弃 H2 的一个精细化主张
- **审稿风险**：低。"环境内加性模型 ≡ 基因型主效应"是数学事实而非弱基线选择，可正面陈述

### 方案 2：改用环境内 RMSE（水平敏感）

**做法**：Δ_RMSE(e) = RMSE(G+E, e) − RMSE(G∘z, e)，正值表示交互建模有益。

- **Δ(e) 含义**：与协议 §4.3 原意一致——两模型共享同一 z_e，差异仅来自显式交互项
- **重跑成本**：**全量 LOEO 重跑**。当前 `_run_one_fold` 仅返回 PCC 汇总，未保存逐样本预测；四作物约 1209 折 × 2 臂。参考玉米 269 折全量约 5 小时 → 估计 1–2 天
- **协议改动**：§6 已列 RMSE 为指标，无需新增条款；§4.4 需将主图 Y 轴改为 Δ_RMSE
- **代价**：
  - RMSE 由环境均值水平主导，若 G+E 的 z_e 已能准确预测环境均值，两臂 RMSE 接近，Δ 信噪比低
  - 跨作物量纲不同，须按作物 z-score 标准化（协议 §10 R5 已预见）
  - 当前基因型侧为学习 embedding 而非标记，绝对预测精度有限，RMSE 可能被基因型侧误差淹没
- **建议**：作为**伴随指标**而非唯一主指标

### 方案 3：升级基线为 FW 反应范数（保留排序指标）

**做法**：Δ_FW(e) = PCC(G∘z, e) − PCC(FW, e)，其中 FW 为 Finlay–Wilkinson 反应范数 `ŷ = μ + g_i + b_i × EnvIndex_e`。

- **关键性质**：FW 的 `b_i × EnvIndex_e` 项**逐基因型斜率不同**，因此在环境间会重排序基因型——它是一个秩-1 交互模型，**不退化**
- **Δ(e) 含义**：学习到的低秩交互相对**经典 envirotyping 反应范数**的增量——这比"相对无交互零模型"更贴近本文的实际贡献主张
- **重跑成本**：中。FW 已列于协议 §5 基线墙第 4 项但尚未实现；需实现 + 重跑四作物 LOEO
- **协议改动**：§4.3 的对照臂从"G+E 加性"改为"FW 反应范数"，§4.4 主图 Y 轴定义相应更新
- **代价**：Δ 的绝对值会显著小于方案 1（FW 是强得多的基线），H2 的可检出效应可能进一步减弱
- **附加收益**：直接回应"学习索引是否优于手工 envirotyping"这一审稿人必问问题（协议 §10 R2 撞车风险项）

### 方案 4：双层 Δ 并行报告

**做法**：同时报告
- Δ_rank(e)（方案 1，零成本，衡量环境条件化总价值）
- Δ_level(e)（方案 2，衡量共享编码下的纯交互增益）

- **重跑成本**：同方案 2（Δ_rank 复用现有结果）
- **代价**：主图需两条曲线或两个面板，叙事复杂度上升；两个 Δ 若方向不一致需额外解释
- **收益**：两个指标回答不同问题，互为稳健性检验；审稿人质疑任一指标时另一指标可作支撑

## 4. 决策

### 4.1 选定方案（2026-08-06 决定）

**方案 3（主）+ 方案 1（附）**

| 项 | 决定 |
|----|------|
| 主指标 | Δ_FW(e) = PCC(G∘z, e) − PCC(FW, e) |
| 主对照臂 | Finlay–Wilkinson 反应范数（协议 §5 基线墙第 4 项） |
| **FW 环境指数** | **环境均值产量**（文献标准定义），`b_i` 由训练折内观测的训练环境均值估计 |
| 附指标 | Δ_rank(e) = PCC(G∘z, e) − PCC(无 G×E 零模型, e)，零重跑成本，作附录 |
| 暂缓 | 方案 2（环境内 RMSE），待基因型侧升级为标记嵌入后再评估 |

### 4.2 泄漏安全实施要求（关键）

FW 预测式 `ŷ = μ + g_i + b_i × E_e`。留出环境的 `E_e` **不可观测**（其观测均值即待预测量），故：

1. `b_i` 斜率：在训练折内用**观测到的训练环境均值**估计（即 §4.1 选定的环境均值产量定义）
2. `Ê_e`（留出环境指数）：**必须**由训练折内拟合的模型从环境协变量预测，可复用协议 §4.2 辅助任务 A 的"从 z_e 线性读出环境均值"机制，或对 R1 特征做岭回归
3. **严禁**使用留出环境的实测均值作为 `E_e`——该操作构成直接标签泄漏

因 `b_i` 逐基因型不同，`Ê_e` 的取值会改变环境内基因型排序，故 FW 在环境内排序指标下**不退化**——这是方案 3 成立的前提。

### 4.3 选型理由

1. **方案 3 让 Δ 测量真正有科学价值的量**。方案 1 的 Δ 回答"环境重要吗"——答案先验为是，且其 Δ>0 几乎不可能失败，作为 H2 的检验缺乏鉴别力。方案 3 回答"学习环境索引是否优于经典反应范数"，这才是本文相对文献的增量主张
2. **FW 已在协议 §5 基线墙内**，实现它本就是既定工作，不是新增负担
3. **方案 1 零成本保留**为"环境条件化总价值"的描述性结果，同时其现有四作物结果可直接作为附录
4. **方案 2 暂缓**：在基因型侧仍为学习 embedding（非标记）的当前阶段，RMSE 的信噪比预期最差；待基因型侧升级为标记嵌入后再评估是否补做

**需要注意的下游影响**：方案 3 会使 Δ 绝对值进一步缩小，H2"无可检出效应"的结论**大概率不变甚至加强**。若目标是抢救 H2，方案 3 并非有利选择；若目标是得到一个经得起审稿的诚实结论，方案 3 最稳。这一点需在选型时明确权衡。
